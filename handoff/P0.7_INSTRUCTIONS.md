## Expected runtime, VRAM and RAM

- **Runtime:** roughly 5–10 minutes for 20 epochs. This is an **estimate, not a
  measurement.** One training epoch of this exact model took ~41 s on my CPU with data
  loading in the main process, which is mostly PIL decoding of 60,000 images. With two
  loader workers on Colab it should be well under that. The script also stops cleanly at
  `--max-minutes 60`.
- **VRAM:** tiny. 6,138 parameters and batches of 128 × 28×28 images. Expect a few
  hundred MB at most, mostly the CUDA context. Allocated peak VRAM is recorded in the
  result as `peak_vram_mb_this_session`.
- **System RAM:** roughly 1–2 GB. MNIST is ~50 MB in memory.
- **Disk:** ~12 MB MNIST download into the ephemeral `/content`. Checkpoints are about
  70 KB each on Drive.

## What the run actually does

- **Model:** `zk_model`, 6,138 parameters (budget: under 10,000). It has three 3×3 stride-2
  convolutions with ReLU (8, 16, 16 channels), taking 28×28 down to 4×4, then a linear
  layer from 256 features to 10 logits. There is no BatchNorm, no dropout and no pooling,
  so the exported graph for Phase 8 is only Conv, Relu, Flatten and a linear layer. Each
  input produces 2,608 ReLU outputs. The script refuses to run if the model is over
  budget.
- **Training:** all 60,000 MNIST training images. There is no attacker holdout, because
  `zk_model` is never attacked. No augmentation. SGD with nesterov, lr 0.05, momentum 0.9,
  weight decay 5e-4, cosine annealing over 20 epochs, and a linear warmup over the first
  epoch. The training loop is the same one P0.5 used.
- **Why lr 0.05 and not P0.5's 0.1:** this model has no BatchNorm, so 0.05 is the
  cautious choice. Before packaging, I ran one CPU epoch each at lr 0.05 and 0.1, with
  and without warmup, on the training set only, to check for P0.5's collapse. All four
  learned normally (train accuracy 87–94% after one epoch). No test-set evaluation was
  involved, and none of those numbers is a result.
- **Evaluation:** top-1 accuracy on the official 10,000-image MNIST test set. The exported
  weights are from the final epoch.
- **Normalisation** (mean 0.1307, std 0.3081) happens outside the model and is recorded
  in the result, because the EZKL input pipeline in Phase 8 has to reproduce it.
